Flujo de Datos

Arquitectura del Pipeline en Streaming

Un flujo continuo de audio sin pausas molestas ni latencias acumulativas. Cada componente está optimizado para responder en menos de 1 segundo.

1
WebRTC / SIP

Transporte de Audio

LiveKit Cloud gestiona la sesión de audio bidireccional de baja latencia con códec Opus a 48kHz.

2
Deepgram Nova-3

STT Streaming

Transcripción en streaming en español peninsular con Silero VAD para detección de turnos de habla (<300ms).

3
DeepSeek V3

Cerebro / LLM

Modelo conversacional conectado vía API OpenAI-compatible. Respuestas concisas, empáticas y de tono ejecutivo.

4
Piper Local ONNX

TTS en Memoria

Síntesis local in-process a 22kHz (0€ de costo). Emite audio PCM en menos de 50ms sin servidores externos.

5
n8n Cloud

Post-Llamada CRM

Al colgar, se extrae el lead estructurado (nombre, teléfono, fecha, motivo) y se despacha vía webhook HTTP POST.

Garantías Técnicas

Seguridad y Reglas de Oro

Restricciones inquebrantables del proyecto para garantizar aislamiento, seguridad de secretos y economía.

PROHIBIDO

Cero Twilio

Prohibido Twilio bajo ningún concepto. Toda la telefonía se basa en SIP troncal nativo sobre LiveKit, ahorrando hasta 90% en comisiones.

AISLAMIENTO

Sin Modificar Rebeca AI

El chatbot web existente en producción (repo welux-events) no se toca ni se altera en absoluto. Es un repositorio independiente.

CONFIDENCIALIDAD

Hoja de Ruta

¿Qué Sigue para la Fase 2?

Una vez validada la conversación por WebRTC en Fase 1, se procederá a la interconexión con la red telefónica pública de Luxemburgo.

Etapa 1

Número Virtual +352

Adquisición de un número telefónico directo de Luxemburgo mediante proveedor europeo (Telnyx o Vonage) configurado vía SIP Trunk.

Etapa 2

Voz Premium de Alta Fidelidad

Transición opcional de Piper TTS a modelos de voz hiperrealista (Deepgram Aura o Cartesia Sonic) para matices telefónicos humanos.

Etapa 3

Notificación Multicanal

Ampliación del workflow de n8n para enviar alertas instantáneas con el lead y audio de la llamada al dueño vía WhatsApp y Telegram.
